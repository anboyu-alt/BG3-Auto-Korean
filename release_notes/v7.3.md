## 🇰🇷 한국어

**v7.3은 번역에 쓰는 AI 모델을 구글 Gemini 최신 세대로 바꾼 판입니다.** 구글이 2.5 세대 모델을 새로 발급한 API 키에 더 이상 제공하지 않아, 새로 키를 받은 사용자는 번역이 실패할 수 있었습니다.

### 바뀐 것
- 🤖 **기본 모델 gemini-3.5-flash-lite** — 폴백은 gemini-3.1-flash-lite입니다. 2.5 세대 모델은 목록에서 뺐습니다.
- ⚙️ **선택 모델 교체** — 번역 탭 모델 목록의 2.5 Flash·Pro를 **gemini-3.8-flash**(속도·품질 균형)와 **gemini-3.1-pro-preview**(최고 품질)로 바꿨습니다.
- 🔄 **예전 설정 자동 정리** — 이전 버전에서 2.5 모델을 골라 두었다면 실행할 때 새 기본 모델로 자동 전환됩니다.
- 🧩 **Gemini 3 호출 방식 대응** — 3 세대 모델에 맞는 추론 설정을 보내도록 고쳤습니다.

### 설치 방법
1. 아래 **`BG3_ModTranslator_v7.3.zip`** 다운로드
2. **모든 파일**을 한 폴더에 압축 해제
3. 폴더 안의 **`BG3_ModTranslator.exe`** 실행

> ⚠️ 번역 결과물(.pak)은 **개인 사용 전용**입니다. 재배포하려면 반드시 원작자 허가를 받으세요.

## 🇬🇧 English

**v7.3 updates the AI models used for translation to Google's current Gemini generation.** Google no longer offers the 2.5 models to newly issued API keys, so translation could fail for users with a new key.

### Changed
- 🤖 **Default model gemini-3.5-flash-lite** — with gemini-3.1-flash-lite as fallback. The 2.5 models were removed from the list.
- ⚙️ **Optional models replaced** — 2.5 Flash/Pro in the Translate tab's model list are replaced by **gemini-3.8-flash** (balanced speed and quality) and **gemini-3.1-pro-preview** (highest quality).
- 🔄 **Old settings cleaned up automatically** — if you had picked a 2.5 model in an earlier version, the app switches you to the new default on launch.
- 🧩 **Gemini 3 request format** — the app now sends the reasoning setting that Gemini 3 models expect.

### Install
1. Download **`BG3_ModTranslator_v7.3.zip`** below
2. Extract **all files** into one folder
3. Run **`BG3_ModTranslator.exe`** inside that folder

> ⚠️ Translated `.pak` files are for **personal use only**. Get the original author's permission before redistributing.
